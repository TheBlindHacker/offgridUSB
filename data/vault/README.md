# `data/vault/` — Self-Improving SQLite FTS5 Memory & Distillation Vault

At runtime, OffGridUSB creates `memory.sqlite` inside this directory directly on the USB drive:

- **`interactions` & `interactions_fts`:** Full-text searchable episodic ledger of field questions, grounded citations, and audit statuses.
- **`pending_deep_review`:** Uncertain or complex queries recorded on low-spec hardware (`Tier 0` / `Tier 1`) queued for automatic upgrade.
- **`master_notes` & `master_notes_fts`:** Permanent **Verified 70B-Grade Master Field Notes** produced via **Distillation-on-Dock** that travel with the USB drive back to low-spec field laptops.
